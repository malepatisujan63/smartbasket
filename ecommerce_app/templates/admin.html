What Gets Passed to the ML Model on Each Ranking Request
brand (title word 1) price (₹) stars (avg rating) reviews (count) category_name isBestSeller (0/1) text_features (title → CatBoost tokeniser) EAV product features (if available)
Evaluation Method
Temporal 80/20 split (first 80% logs = train, last 20% = test — no future data leakage). Metrics: ROC-AUC (ranking quality) · Precision (positive prediction accuracy) · Recall (how many positives caught) · F1 (harmonic mean). Threshold is auto-tuned to maximise F1 on the precision-recall curve (not hardcoded 0.5).
