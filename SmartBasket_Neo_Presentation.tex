            \item \textbf{Stage 2: Precision Scoring}: Combines 5 distinct signals into a score from $0.0$ to $1.0$.
            \item \textbf{Stage 3: Smart Re-Ranking}: Removes duplicate durables and injects category variety.
            \item \textbf{Stage 4: Top-6 Delivery}: Shows the 6 best items with transparent XAI explanations.
        \end{enumerate}
    \end{column}%
    \begin{column}{0.46\textwidth}

            \item \textbf{Stage 2}: Scores each candidate using text, co-orders, and ratings.
            \item \textbf{Stage 3}: Hides other identical TVs, but boosts HDMI cables and soundbars.
            \item \textbf{Stage 4}: Instantly displays 6 relevant items in under $10\text{ ms}$!
        \end{itemize}

\begin{frame}[fragile]{Automated Preprocessing \& Feature Engineering Pipeline}
\begin{columns}[T]
    \begin{column}{0.50\textwidth}
        {\color{brandred}\textbf{Simple English Concept}}:
        \begin{itemize}\scriptsize
            \item Real shopping data is full of errors: missing values, typos, and crazy price extremes.
            \item This pipeline automatically detects outliers, transforms categorical text into numbers, and standardizes scales so models learn reliably.
        \end{itemize}
        {\color{brandorange}\textbf{Mathematical Formulas \& Term Definitions}}:
        \begin{itemize}\scriptsize
            \item \textbf{IQR Outlier Detection Bounds}:
            $$[\text{Lower}, \text{Upper}] = [Q_1 - 1.5 \cdot \text{IQR}, \; Q_3 + 1.5 \cdot \text{IQR}]$$
            \begin{itemize}\tiny
                \item $Q_1$: $25^{\text{th}}$ percentile of feature values (lower quartile).
                \item $Q_3$: $75^{\text{th}}$ percentile of feature values (upper quartile).
                \item $\text{IQR} = Q_3 - Q_1$: Interquartile Range (middle 50\% spread).
            \end{itemize}
            \item \textbf{Standard Normal Scaling}: $z = \frac{x - \mu}{\sigma}$ ($x$: raw feature, $\mu$: mean, $\sigma$: standard deviation).
        \end{itemize}
        {\color{brandred}\textbf{Real-Time Example \& Sample Calculation}}:
        \begin{itemize}\scriptsize
            \item In an audio store, normal prices have $Q_1 = \$30, Q_3 = \$120 \implies \text{IQR} = \$90$.
            \item Upper limit: $120 + 1.5(90) = \$255$.
            \item A newly listed luxury gold cable is priced at $x = \$450$.
            \item Since $\$450 > \$255$, it is capped to $\$255$ so it does not distort training.
            \item Standardized score ($\mu = \$60, \sigma = \$30$): $z = \frac{120 - 60}{30} = \mathbf{+2.0}$.
        \end{itemize}
    \end{column}%
    \begin{column}{0.46\textwidth}
\begin{lstlisting}[language=Python]
# ml/preprocessing/pipeline.py
class AutomatedPreprocessingPipeline:
    def __init__(self, scaling="standard", outlier="iqr"):
        self.cleaner = DataCleaner(outlier_method=outlier)
        self.encoder = CategoricalEncoder()
        self.scaler = FeatureScaler(method=scaling)
        self.selector = FeatureSelector()

    def fit_transform(self, df: pd.DataFrame, target_col: str):
        # 1. Clean outliers and null values
        df_clean = self.cleaner.fit_transform(df)
        
        # 2. Encode categorical features safely
        df_enc = self.encoder.fit_transform(df_clean, target_col)
        
        # 3. Scale numerical features
        self.scaler.exclude_cols = [target_col]
        df_scaled = self.scaler.fit_transform(df_enc)
        
        # 4. RFE feature selection
        return self.selector.fit_transform(df_scaled, target_col)
\end{lstlisting}

% SLIDE 5: RETRIEVAL STREAM 1A - CONTENT TF-IDF + TRUNCATED SVD
% =========================================================================
\begin{frame}[fragile]{Stream 1A: Content TF-IDF + TruncatedSVD Semantic Embeddings}
\begin{columns}[T]
    \begin{column}{0.50\textwidth}
        {\color{brandred}\textbf{Simple English Concept \& The Vocabulary Dilemma}}:
        \begin{itemize}\scriptsize
            \item \textbf{The Flaw in Word Matching}: If a shopper looks at a \textit{"Noise-Cancelling Headphone"} and an item is titled \textit{"Over-Ear Acoustic Wireless Headset"}, standard word search fails because the exact words differ!
            \item \textbf{Our Solution}: We convert text to TF-IDF, then use \textbf{TruncatedSVD} (Latent Semantic Analysis) to compress 5,000 word columns into 30 dense concept dimensions. Words with similar meanings map to the same direction!
        \end{itemize}
        {\color{brandorange}\textbf{Mathematical Formulation \& Term Definitions}}:
        \begin{itemize}\scriptsize
            \item \textbf{TF-IDF Formula}: $\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \left[ \ln\left(\frac{1 + |D|}{1 + \text{DF}(t, D)}\right) + 1 \right]$
            \begin{itemize}\tiny
                \item $\text{TF}(t, d)$: How many times term $t$ appears in product description $d$.
                \item $|D|$: Total product count in catalog ($20,000+$ items).
                \item $\text{DF}(t, D)$: How many products mention term $t$. Common words ("the", "item") get $\approx 0$ weight; rare technical terms get high weight.
            \end{itemize}
            \item \textbf{Cosine Semantic Similarity}: $\text{Sim}(A, B) = \frac{\mathbf{e}_A \cdot \mathbf{e}_B}{\|\mathbf{e}_A\|_2 \|\mathbf{e}_B\|_2 + \epsilon}$
            \begin{itemize}\tiny
                \item $\mathbf{e}_A, \mathbf{e}_B$: 30-dimensional SVD semantic vectors of Products A and B.
            \end{itemize}
        \end{itemize}
        {\color{brandred}\textbf{Real-Time Example \& Step-by-Step Calculation}}:
        \begin{itemize}\scriptsize
            \item \textbf{Product A}: \textit{"Sony WH-1000XM5 Noise Canceling Headphones"} $\implies \mathbf{e}_A = [0.80, 0.60]$.
            \item \textbf{Product B}: \textit{"Bose QuietComfort Wireless Acoustic Headset"} $\implies \mathbf{e}_B = [0.60, 0.80]$.
            \item \textbf{Step 1 (Dot Product)}: $\mathbf{e}_A \cdot \mathbf{e}_B = (0.80 \times 0.60) + (0.60 \times 0.80) = 0.48 + 0.48 = \mathbf{0.96}$.
            \item \textbf{Step 2 (Magnitudes)}: $\|\mathbf{e}_A\| = \sqrt{0.8^2 + 0.6^2} = 1.0, \; \|\mathbf{e}_B\| = \sqrt{0.6^2 + 0.8^2} = 1.0$.
            \item \textbf{Step 3 (Cosine Match)}: $\text{Sim} = \frac{0.96}{1.0 \times 1.0} = \mathbf{0.96}$ (Extremely strong semantic match!).
        \end{itemize}
    \end{column}%
    \begin{column}{0.46\textwidth}

% SLIDE 6: RETRIEVAL STREAM 1B - MATRIX FACTORIZATION (SVD)
% =========================================================================
\begin{frame}[fragile]{Stream 1B: Collaborative Matrix Factorization (Low-Rank SVD)}
\begin{columns}[T]
    \begin{column}{0.50\textwidth}
        {\color{brandred}\textbf{Simple English Concept}}:
        \begin{itemize}\scriptsize
            \item Shoppers who liked the same things in the past will probably like the same things in the future.
            \item SVD compresses a massive table of user ratings into two smaller tables: user taste factors and product attribute factors ($k=20$).
        \end{itemize}
        {\color{brandorange}\textbf{Mathematical Formulation \& Term Definitions}}:
        \begin{itemize}\scriptsize
            \item \textbf{Matrix Factorization}: $R \approx U \cdot \Sigma \cdot V^T = \hat{R}, \quad \hat{r}_{u, i} = \mathbf{u}_u^T \mathbf{v}_i$
            \begin{itemize}\tiny
                \item $R \in \mathbb{R}^{M \times N}$: Sparse rating table ($M$ shoppers, $N$ products).
                \item $U \in \mathbb{R}^{M \times k}$: Shopper latent preference matrix ($k=20$ factors).
                \item $V \in \mathbb{R}^{N \times k}$: Product latent attribute matrix ($k=20$ factors).
                \item $\hat{r}_{u, i}$: Predicted rating score of shopper $u$ for product $i$.
            \end{itemize}
            \item \textbf{Interactive Masking}: $\hat{r}_{u, i} = -\infty \;\; \forall i \text{ where } R_{u, i} > 0$ (prevents re-recommending already purchased items).
        \end{itemize}
        {\color{brandred}\textbf{Real-Time Example \& Sample Calculation}}:
        \begin{itemize}\scriptsize
            \item Shopper Alice has latent taste vector: $\mathbf{u}_{\text{Alice}} = [0.90, 0.30]$.
            \item Logitech Wireless Mouse factor vector: $\mathbf{v}_{\text{Mouse}} = [0.80, 0.40]$.
            \item Predicted Rating: $\hat{r} = (0.90 \times 0.80) + (0.30 \times 0.40) = 0.72 + 0.12 = \mathbf{0.84}$.
            \item If Alice already bought this mouse, score is masked to $-\infty$!
        \end{itemize}
    \end{column}%
    \begin{column}{0.46\textwidth}
\begin{lstlisting}[language=Python]
# ml/recommendation/collaborative.py
from sklearn.decomposition import TruncatedSVD
import numpy as np

# 1. Build sparse user-item rating matrix R (M x N)
R = build_interaction_matrix(users, items)

# 2. Decompose into k=20 latent factors
k = min(20, min(R.shape) - 1)
svd = TruncatedSVD(n_components=k, random_state=42)
u_factors = svd.fit_transform(R)      # (M x k)
v_factors = svd.components_           # (k x N)

# 3. Vectorized user score reconstruction
preds = np.dot(u_factors[u_idx], v_factors)

# 4. Mask existing interactions with -inf
preds[R[u_idx] > 0] = -np.inf

# 5. Extract top candidates for candidate pool
top_candidate_indices = np.argsort(preds)[::-1][:35]
\end{lstlisting}
    \end{column}
\end{columns}

% SLIDE 7: RETRIEVAL STREAM 1C - NEURAL COLLABORATIVE FILTERING (NCF)
% =========================================================================
\begin{frame}[fragile]{Stream 1C: Neural Collaborative Filtering (NCF) Deep Architecture}
\begin{columns}[T]
    \begin{column}{0.50\textwidth}
        {\color{brandred}\textbf{Simple English Concept}}:
        \begin{itemize}\scriptsize
            \item Linear multiplications assume shopper behavior is simple. Real shopping has non-linear, multi-dimensional connections.
            \item NCF feeds user and item embeddings into a Multi-Layer Perceptron (MLP) to learn deep purchase probabilities (\textit{He et al., WWW 2017}).
        \end{itemize}
        {\color{brandorange}\textbf{Mathematical Equations \& Term Definitions}}:
        \begin{itemize}\scriptsize
            \item \textbf{Embedding Concatenation}: $\mathbf{z}_0 = [\mathbf{p}_u \,\|\, \mathbf{q}_i] \in \mathbb{R}^{64}$
            \begin{itemize}\tiny
                \item $\mathbf{p}_u \in \mathbb{R}^{32}$: User embedding; $\mathbf{q}_i \in \mathbb{R}^{32}$: Product embedding.
            \end{itemize}
            \item \textbf{Deep MLP}: $\mathbf{z}_1 = \text{ReLU}(W_1 \mathbf{z}_0 + b_1)$ [$64 \to 128$], $\mathbf{z}_2 = \text{ReLU}(W_2 \mathbf{z}_1 + b_2)$ [$128 \to 128$], $\mathbf{z}_3 = \text{ReLU}(W_3 \mathbf{z}_2 + b_3)$ [$128 \to 64$].
            \item \textbf{Output Purchase Probability}: $\hat{y}_{ui} = \sigma(W_4 \mathbf{z}_3 + b_4) = \frac{1}{1 + e^{-a_{ui}}}$.
            \item \textbf{Binary Cross-Entropy Loss}: $\mathcal{L} = - [y \ln \hat{y} + (1 - y)\ln(1 - \hat{y})]$.
        \end{itemize}
        {\color{brandred}\textbf{Real-Time Example \& Sample Calculation}}:
        \begin{itemize}\scriptsize
            \item Shopper visits Gaming section; neural net evaluates an RGB Mechanical Keyboard.
            \item Network outputs final logit $a_{ui} = 1.386$.

\begin{columns}[T]
    \begin{column}{0.50\textwidth}
        {\color{brandred}\textbf{Simple English Concept}}:
        \begin{itemize}\scriptsize
            \item Keeps the store running smoothly!
            \item Calculates the Safety Stock cushion and the exact Reorder Point (ROP) to trigger purchase orders before items run out.
        \end{itemize}
        {\color{brandorange}\textbf{Mathematical Formulations \& Terms}}:
        \begin{itemize}\scriptsize
            \item \textbf{Safety Stock (SS for 95\% Service Level)}: $SS = Z \cdot \sqrt{L} \cdot \sigma_d$
            \begin{itemize}\tiny
                \item $Z = 1.65$: Normal distribution factor for 95\% satisfaction.
                \item $L$: Supplier delivery lead time in days.
                \item $\sigma_d$: Standard deviation of daily customer demand.
            \end{itemize}
            \item \textbf{Reorder Point (ROP)}: $\text{ROP} = (d \cdot L) + SS$ ($d$: daily sales velocity).
            \item \textbf{Economic Order Quantity}: $\text{EOQ} = \sqrt{\frac{2 \cdot D \cdot S}{H}}$ ($D$: annual demand, $S$: order fee, $H$: holding cost).
        \end{itemize}
        {\color{brandred}\textbf{Real-Time Inventory Example}}:
        \begin{itemize}\scriptsize
            \item Daily sales $d = 8$ units/day, $\sigma_d = 2$ units, Delivery time $L = 9$ days.
            \item Safety Stock: $SS = 1.65 \times \sqrt{9} \times 2 = 1.65 \times 3 \times 2 = \mathbf{9.9} \approx \mathbf{10\text{ units}}$.
            \item Reorder Point: $\text{ROP} = (8 \times 9) + 10 = 72 + 10 = \mathbf{82\text{ units}}$.
            \item \textbf{Trigger}: If warehouse stock drops $\le 82$, trigger restocking PO!
        \end{itemize}
    \end{column}%

\begin{frame}[fragile]{Enterprise MLOps: Model Registry \& Automated Drift Monitoring}
\begin{columns}[T]
    \begin{column}{0.50\textwidth}
        {\color{brandred}\textbf{Simple English Concept}}:
        \begin{itemize}\scriptsize
            \item Over time, customer habits shift and models get stale (called "Data Drift").
            \item Our MLOps system monitors incoming production data using statistical tests (PSI and KS) and automatically retrains models when drift is detected!
        \end{itemize}
        {\color{brandorange}\textbf{Mathematical Formulation \& Terms}}:
        \begin{equation*}
            \text{PSI} = \sum_{b=1}^B \left( P_b - Q_b \right) \times \ln\left(\frac{P_b}{Q_b}\right)
        \end{equation*}
        \begin{itemize}\scriptsize
            \item $P_b$: Percentage of current production samples in bin $b$.
            \item $Q_b$: Percentage of baseline training samples in bin $b$.
            \item Thresholds: $\text{PSI} < 0.10$ (Stable); $0.10 \le \text{PSI} < 0.25$ (Warning); $\mathbf{\text{PSI} \ge 0.25}$ (\textbf{Critical Drift $\to$ Auto-Retrain!}).
        \end{itemize}
        {\color{brandred}\textbf{Real-Time Example (Black Friday Spending Shift)}}:
        \begin{itemize}\scriptsize
            \item Price feature split into 2 bins. Baseline: $Q = [0.50, 0.50]$. Current: $P = [0.20, 0.80]$.
            \item Bin 1: $(0.20 - 0.50) \times \ln(0.20/0.50) = (-0.30) \times (-0.916) = \mathbf{0.2748}$.
            \item Bin 2: $(0.80 - 0.50) \times \ln(0.80/0.50) = (+0.30) \times (+0.470) = \mathbf{0.1410}$.
            \item Total $\text{PSI} = 0.2748 + 0.1410 = \mathbf{0.4158}$. Since $\mathbf{0.4158 \ge 0.25}$, retrain triggered!
        \end{itemize}
    \end{column}%

class EnterpriseDriftDetector:
    def detect_data_drift(self, baseline_df, current_df):
        critical_drifts = []
        for col in baseline_df.select_dtypes('number').columns:
            base_arr = baseline_df[col].dropna().values
            curr_arr = current_df[col].dropna().values
